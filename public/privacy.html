Privacy Policy

Contempra Dashboard · Last updated November 6, 2026

Contempra Dashboard is an internal tool used by the staff of Contempra Signs to manage work orders. It is not offered to the public.

What we access

  • Google Sheets: the dashboard reads and writes the company's own work order sheet so that dockets created in the dashboard appear in the sheet and changes in the sheet appear in the dashboard.
  • Google Drive: the dashboard saves a PDF copy of each docket in a "Contempra Dockets" folder in the company's Drive. It can only see the files it creates.
  • Staff accounts: name, username, role and access level of each employee.

How we use it

The information is used only to run Contempra Signs' production workflow: showing work orders, assigning jobs, tracking progress and billing status. It is never sold, shared with third parties or used for advertising.

Where it is stored

Data is stored in the company's Google account and on Cloudflare, which hosts the dashboard. Access to Google is granted by the company's account owner and can be revoked at any time from that Google account or from the dashboard's Admin page.
